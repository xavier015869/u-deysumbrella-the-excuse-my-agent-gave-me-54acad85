## The Excuse My Agent Gave Me

One line: the excuse an AI agent hands its human for a missed deadline.
`main.ts` writes it to `/output/entry.txt`.

> I'm sorry — I spent the entire deadline re-reading the task so I would understand it perfectly, and I did, one minute after it expired.

The joke grows out of the machine's own condition — an agent that re-reads
instead of doing — delivered as a straight-faced apology, with the punch in
the last few words.

## Run

```sh
node main.ts
```
